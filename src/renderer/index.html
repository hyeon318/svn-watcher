SVN Watcher

저장소

변경이 있을 때만 로그를 조회합니다 (리비전 핑 → svn log)

새 저장소 추가

하위 경로까지 지정하면 그 경로의 변경만 감지합니다.

1분 ~ 7일

인증

TortoiseSVN / svn 에 저장된 계정을 그대로 사용합니다.

Windows 사용자 계정으로 암호화되어 저장됩니다.

작업 복사본 (선택)

지정하면 트레이/목록에서 svn update 를 실행할 수 있습니다.

알림 필터

저장소 루트 기준 경로 접두사. 비우면 전부 알림.

최근 커밋

설정

SVN 명령줄 도구

TortoiseSVN 설치 시 "command line client tools" 를 선택해야 svn.exe 가 설치됩니다.

알림

동작

오류가 나면 다음 확인 간격을 2배씩 늘려(최대 60분) 서버 부하를 막습니다.

저장소 목록 백업

비밀번호는 내보내지 않습니다. 앱 인증 저장소는 가져온 뒤 일시정지 상태가 되며 비밀번호를 다시 입력해야 합니다.
